## 🚀 Как использовать

### Сборка на x86/x64
```bash
cmake -B build
cmake --build build
```

### Сборка на ARM Debian 9
```bash
# Установить зависимости
sudo apt-get install -y build-essential cmake \
    libboost-system-dev libboost-thread-dev libboost-log-dev \
    libpoco-dev libssl-dev libsqlite3-dev

# Собрать
mkdir -p build && cd build
cmake ..
make -j2
```

**📖 Подробная инструкция:** `docs/ARM_BUILD_GUIDE.md`  
**⚡ Быстрый старт:** `docs/ARM_QUICK_START.md`

При каждой сборке:
- Номер версии автоматически увеличивается
- Выводится: `Build number: 27, Version: 1.0.27`

### Изменить ID терминала
```json
// config/config.json
"gas_station": {
    "StandaloneID": "id0002"
}
```

### Изменить версию
Версия инкрементируется автоматически. Для ручного изменения:
```
// config/build_number.txt
100
```

### Тестирование БД
Запустите приложение:
- **3** - Вставить тестовую транзакцию
- **4** - Вставить тестовую метрологическую запись
- **5** - Показать все транзакции
- **6** - Показать все метрологические записи
